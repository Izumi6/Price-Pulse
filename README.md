## ✨ Features

- **🔍 Instant Search** — Search products by name, brand, or category
- **📊 Side-by-Side Comparison** — View prices from Amazon, Flipkart & Croma at a glance
- **💰 Savings Calculator** — See exactly how much you save buying from the cheapest store
- **🔥 Top Deals** — Auto-curated list of products with the biggest price drops
- **📱 8 Categories** — Smartphones, Laptops, Audio, TVs, Gaming, Tablets, Wearables
- **🎨 Premium Dark UI** — Neon cyan accent, glassmorphism, smooth animations
- **📲 Fully Responsive** — Works perfectly on mobile, tablet, and desktop
- **⚡ Zero Dependencies** — Pure HTML/CSS/JS, no frameworks needed

## 🚀 Quick Start

No build step needed — it's a static site:

```bash
# Clone
git clone https://github.com/Izumi6/Price-Pulse.git
cd Price-Pulse

# Open in browser
open index.html

# Or serve locally
npx serve .
```

## 🎯 How It Works

1. **Browse** — Explore products by category or view all
2. **Search** — Type any product name, brand, or category
3. **Compare** — See prices from 3 major Indian retailers side-by-side
4. **Sort** — Sort by lowest price, highest price, or best savings
5. **Buy** — Click through to the cheapest store and purchase
